# Sezzle full-stack calculator assignment

## Context

Build a full-stack calculator application with a React frontend and a backend
microservice. The frontend should consume the backend API to perform basic and
advanced arithmetic operations. Focus on clean design, maintainable code, and
testable architecture.

The requested delivery window is five business days.

## Requirements

### Functional requirements

#### Operations

- Addition
- Subtraction
- Multiplication
- Division
- Optional: exponentiation, square root, and percentage

#### Frontend (React)

- Intuitive UI for entering input and displaying results.
- Input validation and error handling.
- Responsive design with basic mobile support.

#### Backend (REST API)

- Expose endpoints for calculator operations.
- Validate input and handle edge cases, including division by zero and invalid data.
- Return results in JSON format.

### Non-functional requirements

- Clean, readable, idiomatic code in both layers.
- Unit tests covering key functionality in frontend and backend.
- Documentation covering setup, API usage, and design rationale.
- Optional: a Dockerfile for full-stack deployment.

## Constraints

- Frontend: React, preferably TypeScript.
- Backend: Go, preferred.
- Aim for two to four hours; prioritize correctness, clarity, and maintainability over extras.

## Deliverables

- A Git repository with frontend and backend code.
- A README with setup instructions, API examples, and design decisions.
- Unit tests and a coverage report.
- Optional: Dockerfile to run frontend and backend together.
- A link to the repository for evaluation.
- The prompts used during development.

## README checklist

- Setup instructions.
- How to run the frontend and backend.
- REST API call examples.
- Design decisions and assumptions.
